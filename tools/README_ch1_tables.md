# 第1〜6章の表を図として表示する

本文の正本は `../../教材解説/教材_第1章_消防関係法令(共通).md`。
表を `[[fig:ch1_t01_01|見出し]]` 形式の図マーカーに置き換えています。
第1・2章はテキストカードと比較用画像、第3〜6章は画像で表示します。表示処理は `src/ui/LessonMarkdown.tsx` にあります。

表の文言を直す場合は `../../教材解説/第1章_図表データ.md` を編集します。
これは正本Markdownから分離した26表の元データで、再作図用の入力です。
章JSONを直接編集しないでください。

アプリのディレクトリで以下を順に実行します。

```powershell
python tools/build_ch1_tables.py
python tools/gen_content_json.py 1
python tools/gen_bundled.py
python tools/content_manifest.py
```

作図にはPillowと日本語フォントが必要です。Windowsのメイリオが既定です。
他の環境では `--font 日本語フォントのパス` を指定します。
画像の正本PNGは `../../図/第1章/表/`、配信用JPEGは `assets/figures/` に出力します。
比較・一覧に使う表は行・列を1枚に収め、文字サイズを維持した高解像度画像にします。
内容の訂正は図表正本で行います。第1章の用途区分は、記号や空欄の代わりに「特定」「非特定」と明記しています。

端末への反映には、通常のコンテンツ配信で本文・画像・manifestを配信します。
画像はOTA取得後に表示されます。ローカルでの生成だけでは端末に配信されません。
`figures-tools/build_figures.py` はこの図表の作図には使用しません。

## 第1章の読みやすい表・確認問題（2026-11-06）

第1・2章は、同じ図表正本から `content/lesson-tables.json` も自動生成します。
アプリは計41表（第1章26、第2章15）を通常サイズのテキストで表示し、比較用画像を全画面で開けます。
長い表は「全項目を読む」、用途一覧は検索にも対応します。正本と別にセルの文言を編集しないでください。
第1・2章の表画像は分割しません。画像が未取得でも、同梱テキストの表は読めます。
特定の章だけを再生成しても、他章のテキスト表を保持します。
第2章の適応性表は15対象物から選択・検索でき、選択した行の全13列を「適応する」「適応の表示なし」に分けて表示します。
法令照合時は本文だけでなく `第2章_図表データ.md` の該当セルも訂正して再生成してください。

本文正本には次の学習用ブロックを記述できます。

```markdown
:::check 問1　問題名
問題文
---
**答え：…** 解説。→ Lesson 05
:::

:::steps 手順の見出し
1. 最初の手順
2. 次の手順
:::
```

確認問題の解答は初期状態で非表示です。`→ Lesson 05` の参照は解答を開いた後の復習ボタンになります。
`## 復習 ― 試験前チェック` は通常レッスンから独立した項目になります。
生成スクリプトは正本を `bodyV2` に保存し、従来のアプリ向けに標準Markdownへ変換した `body` も生成します。
旧画面では問題と解説を通常の文章で読め、新画面は `bodyV2` のカード・開閉機能を使います。
教材配信とJS OTAの受信順が前後しても、新記法がそのまま露出しません。どちらの本文も直接編集しないでください。

生成後は `python tools/gen_bundled.py`、`python tools/content_manifest.py` を実行し、
`npx tsx tools/test_markdown.ts`、`npx tsx tools/test_lesson_content.ts`、
`npx tsx tools/test_ch2_content.ts` で正本との一致を確認します。

## 第2〜6章

同じスクリプトに章番号を渡します（引数なしは第1章）。
各章の本文正本は `../../教材解説/教材_第N章_*.md`、
図表の元データは `../../教材解説/第N章_図表データ.md` です。

```powershell
python tools/build_ch1_tables.py 2 3 4 5 6
python tools/gen_content_json.py 2 3 4 5 6
python tools/content_manifest.py
```

第1〜6章の全96表を96枚の図に変換しています。
第2〜6章は計70表・70枚です。
第2章の適応性全体表（ch2_t09）は分割せず、全行・全列を1枚の高解像度画像に収めます。
出力名は `ch2_t09_full.jpg`。再作図しても15分割には戻りません。

過度な分割を避けるため、比較・一覧の15表も全体表に統合しました。
例: 消火器の動作数（7枚→1枚）、各種消火器のまとめ（4枚→1枚）、
用途区分（5枚→1枚）、主要部品（3枚→1枚）。
全体表の列幅は `FULL_TABLE_WIDTHS` で指定します。再生成しても分割に戻りません。
正本Markdownの更新成功後、統合済みの旧分割JPEGは自動的に配信対象から除きます。
