オリジナル練習問題。公式問題の写真・図の転載ではありません。

第1回・鑑別1

図は蓄圧式の粉末消火器の外観図である。記号Aの部分に関する各設問に答えなさい。

  1. Aで示す部分の名称を記入しなさい。
    解答・解説安全栓 / 安全ピン：安全栓は、不意にレバーが操作されることを防ぐ部分である。
  2. その部分の主な働きを語群から選びなさい。
    解答・解説ア：安全栓の働きは「不意にレバーが操作されることを防ぐ」である。
  3. 蓄圧式消火器が、レバー操作だけで薬剤を放射できる理由を説明しなさい。
    解答・解説本体容器内に常時圧力を蓄えており、そのガスの圧力によって消火薬剤を押し出すため。：本体容器内に常時圧力を蓄えており、そのガスの圧力によって消火薬剤を押し出すため。

第1回・鑑別2

図の消火器の外観と放射部の形状を観察し、各設問に答えなさい。

  1. Aで示す部分の名称を記入しなさい。
    解答・解説ホーン / 放射ホーン / ラッパ状ホーン：Aはホーンである。Aはラッパ状の放射ホーン、Bは薬剤を収容する本体容器、Cは操作レバーを指す。

    解答・解説二酸化炭素消火器 / CO2消火器 / 二酸化炭素：二酸化炭素消火器には放射ホーンがあり、薬剤量は総質量等で確認する。

    解答・解説ア：二酸化炭素消火器では質量を測定して薬剤量を確認する。

    解答・解説放射によってホーンが低温になるため、指定された握り部を持って凍傷を防ぐ。：放射によってホーンが低温になるため、指定された握り部を持って凍傷を防ぐ。

  2. Bの孔の名称を記入しなさい。

    解答・解説容器内の残圧によってキャップが飛び出し、人に当たってけがをする危険がある。：容器内の残圧によってキャップが飛び出し、人に当たってけがをする危険がある。

  1. 現在の薬剤質量をkg単位で記入しなさい。
    解答・解説2 / 2.0 / 2kg / 2.0kg / 2キログラム：総質量10kgから容器・弁等8kgを差し引き、2kg。
  2. この測定に適した器具を選びなさい。
    解答・解説ア：質量の確認にははかりを用い、圧力計とは区別する。
  3. 二酸化炭素消火器の薬剤量を確認するため、総質量だけでなく薬剤を除く質量も必要な理由を説明しなさい。
    解答・解説総質量には容器や弁の質量も含まれるため、それらを差し引いて薬剤だけの質量を求める。：総質量には容器や弁の質量も含まれるため、それらを差し引いて薬剤だけの質量を求める。
