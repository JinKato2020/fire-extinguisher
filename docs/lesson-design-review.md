# 教材の読みやすさと学習クイズの改善

対象：全6章、49レッスン。各章の導入・復習を含めた表示は61画面。既存の用語集改善は維持した。

## 読む・理解する・思い出す

クレーン教材の要点カード、本文を隠して答える暗記クイズ、目次移動を参考に、消防教材の図・表・既存の確認問題に合わせて実装した。

- テーマごとにカードを設け、見出し19px・本文16px・行間28pxを基本にした。長い段落は文の切れ目で分割した。
- 重要点は緑、注意点は赤、具体例は青で区別する。見出しも併記し、色だけに依存しない。
- 折りたたみ式の目次から該当箇所へ移動できる。タイトルは本文の先頭と重ねて表示しない。
- 図はカード内の実測幅に合わせて縦横比を保ち、拡大機能を維持した。表は既存の検索・展開・対象選択の機能を引き継ぐ。
- 「本文を読む／暗記クイズ」を切り替える。用語・式、数値、条件・例外に絞り込める。
- 1回最大10か所、1つの本文欄では最大2か所を隠す。同じ答えは重複出題しない。見出し・図・具体例・確認問題の解説は隠さない。
- 空欄をタップして答えの表示を切り替えられる。下部に「本文へ」「すべて表示／隠す」「次の空欄」を固定し、小型画面・文字拡大時の占有面積を抑えた。次の空欄への移動だけでは答えを明かさない。
- 空欄の読み上げ名に答えを含めない。答えを開くと読み上げ名も切り替える。

195問は既存問題を操作しやすくしたもの。新規195問を追加したという意味ではない。第6章の大問内の複数小問は、選択肢と取り違えず記述として保持した。

選択問題は回答前に解説を隠し、選択後に正誤・正解・理由を表示する。未選択では採点できず、もう一度解く操作で選択と結果をリセットする。学習用なので、解説だけ先に確認することもできる。

記述問題は任意の回答メモと解答例を用意し、「要点を説明できた／もう一度見直したい」で自己確認する。文章の自動採点ではないことを画面に明記した。既存の模試の出題・採点・進行は変更していない。

レッスンの末尾に確認状況を表示する。暗記クイズで答えを開いた数を正解数とは数えない。メモ・回答・確認状況は画面内で保持し、レッスン移動時にリセットする。コンテンツ更新時にも古い正解・回答状態を持ち越さない。教材内の操作だけで評価依頼の学習セッションを終了しない。

## 正本と互換性

正本は `../教材解説/教材_第N章_*.md`。JSONを直接編集せず、`python tools/gen_content_json.py` で6章を再生成した。

正本の追加記法：

```md
**{{消防吏員::key}}**
{{3日以内::num}}
{{対象外::trap}}

:::check 問1　例
@choice: 2
正しいものを選んでください。
1. 選択肢A
2. 選択肢B
---
**答え：2。** 理由を説明します。
:::
```

マーカーは本文・箇条書き・囲みの本文に付ける。見出し・表・図・手順・確認問題内には付けない。選択式の正解指定は1始まり。番号付きの小問群には付けない。薬剤名「ハロン1301」などは数字を含んでも用語として分類する。

- `bodyV3`：正本そのまま。新UIが優先して読む。
- `bodyV2`：空欄を通常の語句に戻し、選択式メタデータを除く。以前の確認問題UIで読める。
- `body`：確認問題・手順を通常のMarkdownに戻した旧画面用。

配信順が前後しても旧アプリに専用記号が露出しない。既存のLessonキー・順序・無料範囲・本文の語句・195問の解答・全図参照を保持した。本文の変更は段落分割、3つの見出し追加、出題指定、選択肢表記の整理であり、法令や数値の変更は行っていない。
