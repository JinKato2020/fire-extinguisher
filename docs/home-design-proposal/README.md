## 現状のレビュー

`App.tsx` の `HomeScreen` と `src/ui/styles.ts`、`src/data/stats.ts`、既存 `assets/hero.jpg` を確認した。

1. ヒーローの高さは画面幅×888/853。390px幅では約406pxあり、試験日とレーダーが続くため、教材の入口までの距離が長い。
2. 主な入口は同じ重みの6カードで、「今すぐ何をするか」を選び直す必要がある。前回の読書位置から再開するカードはない。
3. 学習の継続は問題への解答数を基に集計している。教材や用語を中心に学ぶ利用者の活動が表れにくい。
4. 成績の「合格圏／弱点あり」が、学習開始直後にも強く見える構成。少数の回答から実力を断定するように見せず、記録の量と次の復習を案内したい。
5. ヒーロー内にタイトルとコピーが焼き込まれている。新案では背景画像とアプリの文字を分け、文字拡大と着せ替えに対応する。

## 共通UI

横長のヒーロー → 前回の続き → 今日の学び → 学習メニュー → 試験日・進捗の順に整理する。画像を選び直しても、操作位置は変えない。

- 「続きから学ぶ」を第一の行動にし、最初の画面内に置く。
- 教材・用語・クイズの活動をそれぞれ表示する。閲覧と理解・正解は同じ指標として扱わない。
- 連続日数だけでなく、週に学べた日数を表示する。休んだ日を失敗として強調しない。
- 初回は「第1章から始める」、久しぶりの利用には「また、ここから始めましょう」など、利用状況に合わせた案内にする。
- 教材・用語・模試・相関図の4入口を配置し、お気に入りの用語と問題ブックマークは補助リンクとして残す。5つの下部タブは維持する。
- 試験日が未登録なら「試験日を登録」。詳細な成績は既存の模試・成績へ誘導し、ホームでは積み重ねと次の復習を示す。

## ヒーローと配色

|案|雰囲気|狙い|
|---|---|---|
|A アニメ|生成り・控えめな赤・成人の設備点検スタッフ|親しみと伴走感|
|B 実写|白・ネイビー・設備点検の場面|学ぶ先の仕事をイメージ|
|C 風景|ネイビー・暖かな建物の光・人物なし|落ち着きと集中|

ヒーローと配色は独立して選ぶ。比較画像の組み合わせに固定しない。「画像なし」と「端末に合わせる」も候補に含め、最後に選んだ組み合わせを端末内に保存する想定。自動カルーセルや点滅は使わない。

実装時は、本文の文字拡大・明暗両テーマ・44pt以上の操作領域を確認する。今回の画像は390px幅を基準にしたデザイン案であり、実機の最終表示ではない。

## 新たな実装が必要な部分

前回の読書位置、教材・用語の活動記録、レッスンの学習済み状態、見た目の設定保存は提案段階。学習済みの判定方法は、単に開いただけで理解済みと扱わないよう設計する。既存の評価依頼の30秒ルールとは別の記録にする。

画像内の「1レッスン・5語・3問」「今週4日」「14/49」「あと28日」は表示例であり、実際のユーザー情報ではない。

## 制作と確認

ヒーロー3枚はbuilt-in `image_gen`で新規生成した。原画は[アニメ](hero-anime.png)・[実写](hero-photo.png)・[風景](hero-calm.png)。[生成プロンプト一式](generation-prompts.json)を保存した。画像は雰囲気を伝えるヒーロー用であり、教材の構造図や操作説明として使用するものではない。

日本語の文字とUIは確認用の `proposal.html` で構成し、ローカルChromeでPNGに書き出した。[描画確認記録](render-check.json)。アプリのReact Nativeコードへは組み込んでいない。

元のアプリ・教材・アセット328ファイルのハッシュを制作前後で照合する。原画・比較画像・説明はすべて本フォルダー内に保存した。
