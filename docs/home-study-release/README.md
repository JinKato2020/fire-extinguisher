## 教材・用語

教材の本文・具体例・補足と用語の説明カードを無彩色に寄せ、短い語句だけに色と太字、薄い背景を付けた。クレーンの `MaskableText.swift` と `Theme.studyKey` を参照。青は重要語句、緑は数値、赤は条件・注意。凡例を表示し、色だけに依存しない。

教材では既存の正本にある暗記箇所 `{{語句::key|num|trap}}` と短い太字を使う。用語は正本 `../../../教材解説/用語集.md` の106項目に `強調：` メタデータを追加し、`tools/gen_glossary.py` でJSONを再生成した。説明の意味・定義・画像・リンクは変更していない。用語の強調は各説明につき最大3か所、文字数の約35%まで。選択肢の正誤表示や暗記クイズの操作状態は別の目的の色として維持する。

## 評価・リクエスト

初回は利用3日目以降、以後は最短10日間隔。いずれも前回依頼以降に2日以上・3セッション以上の対象学習が必要。教材・用語・問題を前面で30秒以上学び、学習画面を離れて2秒間操作がないときにApple標準APIを呼ぶ。模試は途中離脱も対象だが、試験中には依頼しない。背景復帰だけでは発動せず、設定・モーダル表示時にも抑制する。

アプリ独自の年間3回API呼び出し制限を外した。実際の表示・投稿可否はApple側が制御する。同一バージョンでも呼び出し候補となるが、表示を保証するものではない。評価の有無は無料利用権に影響しない。評価直後の自動メール画面は廃止し、設定の購入欄直下の評価リンクに加え、開発者メッセージ内に評価とメールの常設入口を配置した。満足度や点数で利用者を選別しない。
