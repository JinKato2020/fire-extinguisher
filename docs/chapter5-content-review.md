## 主要な訂正・補強

| 論点 | 改訂後の扱い |
|---|---|
| ハンドル車式バルブ | 「1/4回転以下」を訂正。**1回転と1/4＝1.25回転＝450°以下**。公式講座のPDF画像と規格省令第14条を照合。 |
| 放射量 | 90%と85%の差は5ポイント。放射時間の20℃条件と、放射量・距離の条件を分けた。 |
| 住宅用 | 交換式を除く住宅用の蓄圧式・再充てん不可、放射量85%、据置式ホース5m、ホース設置義務と赤色規定の不準用、使用不可の薬剤を比較。 |
| 能力単位 | Aの模型個数の計算、Bの2試験の平均と切捨て、模型の制約と時間条件を追加。大型は薬剤量と能力単位を両方確認。 |
| 運搬・作動 | 28kg・35kgの境界、数えない操作、自動車用と車載式を整理。製造状況を断定する表記と根拠のない理由付けを削除。 |
| 絵表示と塗色 | 半径と直径、薬剤量の境界、住宅用の例外を明記。ハロンのねずみ色に材質等の例外があることを追加。 |
| 容器・キャップ | 材質・内径による板厚、方式・材質・安全弁による耐圧係数とP/Q、気密性を追加。減圧孔を残圧下で開けてよい根拠にしない。 |
| 放射経路 | ハロゲン化物4kg未満・粉末1kg以下のホース例外、ノズルと本体操作の違い、ろ過網の径と面積の計算を追加。 |
| 安全装置 | 安全栓追加規定の対象、使用済表示と圧力計の限界、作動封板と安全弁の違いを整理。 |
| ガス容器 | 100cm³ちょうどの区分と、封板が破壊される／されない試験を区別。高圧ガス保安法の一部適用除外を「すべて対象外」としない。 |
| 圧力試験 | 二酸化炭素用弁箱の24.5MPa・5分間と、小型加圧用ガス容器の24.5MPa・2分間を比較。 |
| 指示圧力計 | 二酸化炭素・ハロン1301の例外、丸で囲んだ「消」の記号、条件付きの許容誤差と温水試験を整理。 |
| 薬剤規格 | 二酸化炭素・四塩化炭素という省令適用範囲を、検定対象からの除外と区別。「著しい毒性なし」を「無害」としない。 |
| 強化液 | アルカリ金属塩類水溶液の条件を限定して説明。凝固点と消火器の使用温度下限を区別。 |
| 泡・粉末 | 泡倍率と安定性の25%の母数を区別。180μmはふるいの目開きとして説明。吸湿試験と再生粉末の含水率を分けた。 |
| 表示 | 本体の製造年、薬剤容器の製造年月、設計標準使用期限を区別。 |
