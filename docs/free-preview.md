# TestFlightで無料版の表示を確認する

設定 → アプリについて →「バージョン」の行を1.5秒長押しすると、
「開発用（テスト購入）」の「無料ユーザーとして確認」が表示されます。

- 対象はRevenueCatのPro権利がSandbox購入である場合、または開発ビルドのみ。
- スイッチをオンにすると、アプリ全体のPro判定がfalseになります。
- Apple/RevenueCatの購入履歴や権利そのものは変更しません。
- オフにすると本来のPro判定に戻ります。未購入者にProを付与しません。
- 設定は保存しません。アプリプロセスの完全終了後は通常の購入判定です。
- 確認中でも購入ボタンからSDKのテスト購入へ進めます。成功した場合だけ無料確認を解除します。
- 購入のキャンセル・失敗時は無料確認を継続します。復元する場合は先にスイッチを解除します。
- 本番購入のユーザーには開発用設定は表示されません。

検証: `node tools/test_free_preview.cjs` / `npm run tsc`
画面・ロジック更新のため、端末へはiOSコードOTA（EAS Update）で配信します。
