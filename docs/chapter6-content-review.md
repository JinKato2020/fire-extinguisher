## 正確性の修正

| 項目 | 修正後 |
|---|---|
| 実技の合格基準 | 曖昧な「一般に6割」から、公式の実技60%以上へ。筆記の各科目40%以上・全体60%以上も明記。 |
| 問題数・試験時間 | 免除なしは筆記30問、鑑別等5問、合計105分。実技は複数小問がある形式として説明し、5問中3問で合格と換算しない。 |
| 外観の判別 | 設問・薬剤名の表示→構造→外観の順に変更。ノズル形状、レバーの有無、車輪だけで断定する説明を削除。 |
| 圧力計がない場合 | 二酸化炭素・ハロン1301などの蓄圧式もあることを明示。圧力調整器側の計器との混同を防止。 |
| 大型粉末 | 40kg以上という誤記を20kg以上へ。図の40kgは製品例。適応火災の能力単位との両条件を説明。 |
| ろ過網 | 化学泡だけという限定を修正。手動ポンプ式の水、ガラスびんを使う酸アルカリ・強化液も含める。径と面積の基準を区別。 |
| 圧力計の数値 | 0.7〜0.98MPaは図の例と明記。細かい目盛りがない計器から正確な中間値を読まない。緑色でも薬剤量は確認できない。 |
| 部品の対応 | 作動封板／粉上り防止用封板、サイホン管／ガス導入管、減圧孔／安全弁、ホーン／握りを対比。 |
| 断面図 | 粉上り防止用封板の下端位置はメーカー構造図と照合して維持。ガス導入管がガス容器底部から出るように見える描画だけを修正。 |
| 器具・工具 | 固定・開閉・清掃・観察・加圧・測定の用途を分ける。木製ハンマーなら容器を安全にたたけるという旧用語説明を修正。 |
| 測定・計算 | 総質量から薬剤以外を引く条件、絶対圧、充てん比、倍率・単位換算、公式の適用条件を追加。 |
| 学習上の表現 | 「市販テキストの原本を確認」「要原本確認」、名前を誤ると全小問を失点するという断定、満点・出題の保証に相当する表現を除去。 |
