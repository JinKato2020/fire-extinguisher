# ホーム・設定・試験総合解説の整理（2026-11-06）

ユーザー指摘の画像サイズ、残り日数の位置、設定の重複と情報順序を修正。教材R2とproduction iOS OTAの配信・照合を完了し、その後に **v1.3.1（1059）**をビルドしてTestFlightへ送信した。[配信記録](release.json)／[ビルド結果](https://github.com/JinKato2020/fire-extinguisher/actions/runs/42189156832)。

- ヒーローは原画像の縦横比で表示。横長3枚は2:1、既存の縦長画像は853:888。文字量に依存する背景画像を廃止し、人物・消火器を切り取らず、文字拡大によって画像が伸びない。
- 残り日数を画像直下に統合。画像または「編集」から同じホーム編集画面へ進み、試験日はカレンダー、画像は5択で選ぶ。選択時に保存し、日付解除・月移動・閏年にも対応。ホームが開いたまま日付が変わる場合や前面復帰時も残り日数を更新する。読み上げには日付と残り日数を含める。
- ホームは画像／残り日数 → 教材の再開 → 用語・模試の2入口 → 今日の記録 → 総合解説の順。週間記録・閲覧数と補助3機能は展開して見る。無料利用状態は小さな表示に集約し、同じ重さのカードが続く構成と重複入口を減らした。
- 設定の評価リンクは購入の下の1つに統一。「アプリについて」を利用状態直下へ移し、開発者メッセージ・メール・バージョンをまとめた。ホーム画像と試験日の編集はホームに集約し、設定は配色の変更を維持。拡大文字でも項目名と値が折り返す。
- 試験総合解説は30問／5問／105分の概要、合格ライン、科目の内訳、時間配分例、アプリでの学び方に整理。重要語句・数値・注意条件を単語単位で青・緑・赤に強調した。
- 総合解説の正本を ../../../教材解説/試験総合解説.md に置き、tools/gen_exam_guide.py で content/exam-guide.json を生成。新しいキーを同梱・R2配信の対象に登録した。既存6章・用語の本文は変更していない。

試験情報は[試験の方法](https://www.shoubo-shiken.or.jp/shoubou/annai/way.html)と[試験科目及び問題数](https://www.shoubo-shiken.or.jp/shoubou/annai/subject.html)で確認した。アプリの時間配分例と参考採点を公式ルールと区別して記載している。
