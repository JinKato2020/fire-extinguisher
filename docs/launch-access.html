1.3.0 無料開放とフィードバックの運用

対象者と権利

無料開放中に1.3.0以降を初回オンライン起動し、対象確認・権利保存を完了したインストールに、全機能を期限なしで付与する。既存ユーザーのアップデート後の起動も含む。ダウンロードしただけで一度も対象確認を完了していない場合は権利は保存されない。

権利はAsyncStorageの fire6:launch-access:v1 に保存。開放終了後・オフライン時にも維持する。アプリ削除、データ消去、再インストール、機種変更後の引き継ぎは保証しない（ユーザー指定）。App Storeの「購入を復元」は実購入の復元であり、この無料権利の復元ではない。

評価・星の数・レビュー投稿・メール送信を無料権利の条件にしない。既存の実購入者のPro権利はRevenueCatで継続して判定する。

無料開放を終了するとき

python tools/set_launch_access.py --close
git add content/access-policy.json content/_manifest.json
git commit -m "Close new launch-free enrollments"
git push origin main
gh workflow run deploy-content-fire6.yml --ref main

既存の保存済み無料権利は変更しない。終了後、まだ無料権利のない新規インストールでは、従来の無料範囲と買い切りPro（EF_Pro）へ移行する。再開は --open。評価件数・星の平均を自動監視して終了する仕組みはない。終了は運営判断で手動実行する。

新規登録にはキャッシュや同梱設定ではなく、公開URLの最新ポリシーを確認する。通信失敗時は登録せず、購入も保留して再確認を案内する。

評価依頼とメール

初回利用日を端末の現地日付で1日目として、3日目以降の学習の区切りに初回案内する。その後は実際に案内した時刻から最低7日空ける。教材本文・用語の説明・模試問題をそれぞれの学習画面で60秒以上、前景表示した後、戻る・タブ切替・模試終了などでその学習を終えたときが対象。60秒経過だけでは発動しない。用語の章一覧・空の検索結果・ロック中の教材・単なる成績閲覧は対象外。模試は問題間の移動や解答時には一切表示しない。35問の完了は不要で、60秒以上学習後の途中終了も対象。バックグラウンド時間は加算しない。別の学習を続ける場合はその終了まで案内を保留する。期限を過ぎても未利用時には表示せず、次の適切な区切りで一度だけ案内する。複数の画面で同日に繰り返さない。点数・正誤・自信度・無料/有料で対象を選別しない。アプリ起動直後・模試の制限時間中には自動依頼しない。

Apple標準の評価APIを使用。アプリ側の呼出しも365日で3回までに抑制する。実際に評価画面が表示されたか、評価されたか、星が何個かは取得しない。Appleの表示制御やユーザー設定で表示されない場合もある。TestFlightでは標準の評価画面は表示されない。

同じ初回3日目・以後7日周期の区切りに「ご意見・ご要望」のメール導線を表示する。学習画面を離れた後にも見える共通の案内画面に表示し、「閉じる」「今は送らない」で終了できる。Appleの評価画面が出ない場合もメール導線は表示可能。設定からはいつでもメールを開ける。宛先は contact@safa-lang.com。件名とアプリ版番号のみ事前入力し、送信内容はユーザーが編集・送信する。自動送信しない。

設定からの確認

「購入を復元」の下の「アプリを評価する」は、App StoreのアプリID 6823598014 のレビュー投稿ページを開く。通常の表示間隔・年間回数の判定から独立して、いつでも利用可能。

開発ビルド・TestFlightでは、設定の「バージョン」を1.5秒長押しすると開発用の「評価画面を表示」「リクエスト画面を表示」が現れる。無料開放ユーザーもテスト購入なしで利用できる。本番App Store版ではこれらの表示トリガーを出さない。

評価のテストはApple標準APIを直接呼ぶ。TestFlightではOS側で表示できないため、その理由をアラートで案内する。リクエストのテストは通常の案内カードをモーダルに表示し、そこから実際のメール編集画面を開ける。いずれも通常の表示間隔や年間の依頼履歴を変更しない。

ビルド・配信

expo-store-review 9.0.9系列とexpo-application 7.0.8系列（SDK54対応）を追加。新バージョンは1.3.0、runtimeVersionは1.1.0。従来の1.0.0 runtime向けOTAでは配信できず、iOSの新しいビルドが必要。

リリース前に教材R2へ access-policy.json とmanifestを配信し、新ビルドで初回登録を確認する。初回起動はネット接続が必要。今後の開放終了はR2のポリシー配信だけで反映できる。

実機QA：無料期間中の新規起動→全機能、オフライン再起動→権利維持、ポリシー終了→同じインストールは無料維持、終了後の新規インストール→無料範囲/購入画面、実購入の復元、メール編集画面とキャンセル、3日目と以後7日周期の案内。TestFlightで実レビュー投稿は検証できない。端末の日付を変えて本番データで試すより、モックテストで時刻境界を検証する。

自動検証：npm run tsc、node tools/test_launch_runtime.cjs、npx tsx tools/test_launch_rules.ts、node tools/test_free_preview.cjs。

審査メモに加える説明案

This version includes a launch promotion. Installations that complete their initial online eligibility check while enrollment is open receive access to all features without an expiration date for that installation. This access is independent of ratings, reviews, or feedback. It is stored locally and is not guaranteed to transfer after app deletion, reinstallation, or a device change.

When enrollment is closed, existing promotional access remains valid. New users without promotional access may use the standard free content or purchase the existing non-consumable Pro product, EF_Pro. Existing purchases remain restorable.

The app may request an App Store rating through Apple's standard API after a learning checkpoint, starting on the third local calendar day of use, followed by a minimum seven-day interval, and at most three API requests per 365 days. An optional feedback email action is offered at the same checkpoints and is always available in Settings. The app does not require a rating or feedback to unlock functionality.
